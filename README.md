# Bank Customer Retention & Engagement Analytics 🏦

An interactive Streamlit dashboard developed to reframe customer retention strategies. This project analyzes behavioral engagement, product utilization, and relationship depth to predict and mitigate churn, moving beyond standard demographic analysis.

## 📊 Core Features & Engineered KPIs
* **Relationship Strength Index (RSI):** A proprietary 100-point scoring model evaluating activity status, product depth, tenure, and credit card ownership to mathematically quantify loyalty.
* **The "2-Product" Sweet Spot:** Analytics proving that cross-selling a second product maximizes retention, while over-selling (3+ products) triggers severe flight risk.
* **Premium Disengaged Detector:** Identifies high-net-worth customers who hold above-average balances but exhibit zero banking activity, spotlighting silent capital flight risk.
* **Theme-Adaptive UI:** Fully responsive dashboard with custom CSS engineered for seamless Light/Dark mode transitions.

## 🛠️ Technology Stack
* **Language:** Python
* **Framework:** Streamlit
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Plotly (Express & Graph Objects)
